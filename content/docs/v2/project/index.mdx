Pterodactyl is an open-source game server management panel built with PHP, React, and Go. It runs every game server in its own isolated Docker container, and gives administrators and users a fast, friendly interface to manage them.

## Supported Games

Pterodactyl runs each game in a Docker container. This lets you host many different games on one machine without installing each game's dependencies on the machine itself.

The Panel comes with eggs for these games:

- Minecraft, including Vanilla, Paper, Forge, Sponge, and BungeeCord
- Rust
- Counter-Strike: Global Offensive
- Team Fortress 2
- Garry's Mod
- ARK: Survival Evolved
- Insurgency
- Teamspeak 3
- Mumble

The community maintains eggs for many more games and services, such as Terraria, Factorio, and FiveM. You can find them at [pterodactyleggs.com](https://pterodactyleggs.com).

## Responsible Disclosure

Pterodactyl is open source, so anyone can read its code and look for security issues. If you find a security issue, email `support@pterodactyl.io`. Please do not report security issues on our public bug tracker.
