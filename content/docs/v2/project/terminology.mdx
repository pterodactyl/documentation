---
title: Terminology
description: The key terms used throughout the Pterodactyl documentation.
---

**Panel**: Pterodactyl Panel itself, where you manage users, nodes, and servers.

**Node**: A machine that runs Wings. Each node can host many servers.

**Wings**: The Go service that runs on each node. It controls Docker and gives the Panel secure access to that node's servers.

**Server**: A game or application server created by the Panel. Servers run on nodes.

**Docker**: A platform that runs applications in isolated, secure containers.

**Docker Image**: A package with everything an application needs to run, such as Java for a Minecraft server.

**Container**: The isolated environment Docker creates for each server. It limits the server's CPU, memory, and disk use, and keeps it separate from other servers on the same node.

**Egg**: The configuration for one type of server, such as Vanilla, Paper, or BungeeCord for Minecraft.

**Tag**: A label on an egg or a node. Tags group eggs, for example by game, and decide which nodes a server can be deployed to. Tags replace the nests used in 1.x.

**Extension**: A package that adds features to the Panel. See [Extensions](../extensions/index.mdx).

**Yolks**: A curated collection of Docker images for Pterodactyl's eggs.
