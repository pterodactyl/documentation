## Introduction

This page lists the software the Panel needs to run. If you use the [Docker image](./docker.mdx), everything except the database and Redis is already included.

## Panel Requirements

Your server needs the following:

- PHP 8.3 or 8.4
- Composer 2
- MariaDB 10.11 or 11, or MySQL 8 or 9
- Redis
- A web server, such as NGINX, that serves the Panel's `public` directory
- A queue worker and a cron entry for the scheduler

The Panel is tested against each of these PHP and database versions. Other database servers, such as PostgreSQL and SQLite, are not supported.

### PHP Extensions

Most PHP installations already include the extensions the Panel needs, such as OpenSSL, Sodium, and Tokenizer. These usually have to be installed separately:

- BCMath
- Intl
- Mbstring
- PDO MySQL
- XML
- Zip

On Ubuntu, these packages install PHP 8.3 with every required extension:

```bash
apt -y install php8.3 php8.3-{common,cli,gd,mysql,mbstring,bcmath,xml,fpm,curl,zip,intl}
```

To confirm that PHP has everything the Panel needs, run this command from the Panel directory:

```bash
composer check-platform-reqs --no-dev
```

If PHP-FPM uses a different PHP installation from the command line, make sure it has the same extensions.

### Building From Source

2.0 has no release yet, so a Panel installed from the `2.0-develop` branch needs its frontend built from source. The Docker image already contains the built frontend.

To build from source, you need Node.js 22.12 or newer. Run these commands from the Panel directory:

```bash
npm ci
npm run build:production
```

## Operating Systems

Pterodactyl officially supports two ways to run the Panel:

- A native installation on Ubuntu 22.04 or 24.04. See [Getting Started](./getting-started.mdx).
- The [Docker image](./docker.mdx), which supports AMD64 and ARM64.

Other Linux distributions may work, but they often need changes to the installation steps, and we cannot help with those installations. The upgrade from 1.x has been tested on Ubuntu 24.04.

## Wings

Wings runs on each node and manages your game servers with Docker. You install it separately from the Panel. It is not part of the Panel image.

There is no Wings version table for 2.0 yet. Wings 1.13.2 and 1.13.3 work with the 2.0 Panel. In testing, they handled everything below without changes:

- Power actions and server status.
- Files and the console.
- SFTP, with passwords and with SSH keys.
- Schedules.
- Backups.
